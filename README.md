# FE-5680A 铷原子频率标准 · Win10 现代控制台

把 2008 年的 DOS QuickBASIC 程序 `FE5680A.BAS`（Rev C4，作者 Duane C. Johnson / Red Rock Energy）
重写成能在 Windows 10 上直接运行的图形界面程序。**串口协议、频率换算、参考频率格式、EEPROM 指令
以及原版 BASIC-FORTH 风格输入全部保持兼容。**

原来的 `FE5680A.EXE` 是 16 位 DOS 程序，在 64 位 Windows 上无法运行；本程序是 32/64 位通用的
.NET Framework 程序，Win10 自带运行库，**双击即可用，无需安装任何东西。**

---

## 一、快速开始

1. 把 `dist\FE5680A_GUI.exe` 和 `dist\FE5680A.CFG` 放在**同一个文件夹**（CFG 是配置文件）。
2. 双击 `FE5680A_GUI.exe`。
3. 两种用法：
   - **连真机**：下拉框选择串口（例如 COM3/COM5）→ 点 **[连接]** → 自动读取当前参数。
   - **没有硬件也能试**：勾选 **[模拟器]** → 点 **[连接]**，界面会出现一台虚拟的 FE-5680A。

> 串口参数固定 9600, 8, N, 1，无流控（与原程序的 `9600,N,8,1,RS,CS0,DS0,CD0` 一致）。

## 二、界面功能 / 与原版按键对照

| 原 DOS 版按键 | 新界面 | 说明 |
|---|---|---|
| `S` 读参数 | **[读取参数 (S)]** | 读出参考频率、32 位控制字、序列号，并换算成十进制频率 |
| `F` 设输出频率 | **目标频率 / 表达式** + **[设置频率]** | 支持表达式（见下节） |
| `R` 设参考频率 | **参考频率** + **[设置]** | 限 50255000 ~ 50255100 Hz，与原程序同样的限制 |
| `N` 设序列号 | **序列号** + **[设置]** | 8 位十六进制 |
| `E` 存 EEPROM | **[写入 EEPROM]** | 会先弹确认框，写入后掉电保留 |
| `+` `=` `}` `]` | **[+ 4096] [+ 256] [+ 16] [+ 1]** | 递增 |
| `_` `-` `{` `[` | **[- 4096] [- 256] [- 16] [- 1]** | 递减 |
| `M` 倍率 | **倍数** 数字框 | 步进量 = 步长 × 倍数 |
| `B` 二进制 2^23 | 表达式里直接写 `2^23` 或 `8388608` | — |
| `C` 清屏 / `?` 帮助 | **[清空日志]** / 界面上的灰色提示文字 | — |
| `Q` 退出 | 关闭窗口（自动断开串口） | — |

右侧还有：**每 2 秒自动刷新**（定时读回真实状态）、**记录串口收发数据**（把 `->` `<-` 的原始
报文写进日志，调试用）。

日志区会记录每一次操作、错误、以及（勾选后）原始串口报文，颜色区分：发送蓝色、接收绿色、错误红色。

## 三、频率输入：两种风格

输入框里可以写**绝对频率**，也可以写**相对当前频率的表达式**。

### 1. 中缀表达式（默认）

| 输入 | 结果 |
|---|---|
| `10000000` | 10 MHz |
| `F+4` | 当前频率 + 4 Hz |
| `+4` | 同上（以运算符开头会自动接 `F`，对应原程序"栈里先放当前频率"） |
| `-1000` | 当前频率 − 1000 Hz |
| `8.388608e6` | 8388608 Hz |
| `2^23` | 8388608 Hz |
| `(F+4)*2` | 当前频率加 4 再乘 2 |
| `REF/136` | 参考频率 ÷ 136 |

可用名字：`F`（当前输出频率）、`REF`（参考频率）、`PI`、`E`、`MHZ`、`KHZ`。
运算符：`+ - * / % ^` 与括号。

### 2. RPN 原版风格

把下拉框切到 **RPN 原版风格**，按空格分词，栈底自动放入当前频率 —— 和 2008 年那个程序的手感一样：

| 输入 | 结果 |
|---|---|
| `4 +` | 当前频率 + 4 |
| `1e3 -` | 当前频率 − 1000 |
| `8388608` | 直接设为 8388608 |
| `2 23 ^` | 8388608 |
| `10000000 200000 +` | 10200000 |
| `DUP *` | 平方（`SQUARE` / `CUBE` 也支持） |

另外支持 `ABS INT FIX INV LN LOG EXP SIN COS TAN SGN RND SWAP OVER DROP R>D D>R` 等原版词。

勾选 **[输入当作 8 位十六进制控制字]** 后，输入框按控制字解释，例如 `32F0AD8D`。

## 四、关于频率换算（重要）

与原程序完全一致：

```
Fout = (N / 2^32) × Fref          N = (Fout / Fref) × 2^32
```

- `N` 是写入设备的 32 位控制字（界面显示为 8 位十六进制）。
- **受整数量化限制，分辨率 = Fref / 2^32 ≈ 0.0117 Hz**，所以设置 10 MHz 后读回可能是
  10,000,000.000653 Hz —— 这不是误差，是 DDS 的固有步进。
- 参考频率 **设备并不真正使用**，它只用于十进制频率与控制字之间的换算（原程序帮助里也是这么写的）。
  所以它必须和设备的实际参考频率一致，换算出来的频率才有意义。

程序界面上直接写明了这两个公式。

## 五、配置文件 `FE5680A.CFG`

格式与 DOS 版**完全兼容**，两行、带注释：

```
COM4             SERIAL COM PORT
10000.001545     FREQUENCY IN Hz
```

- 必须和 `FE5680A_GUI.exe` 放在同一目录。
- 启动时读入串口号和上次频率；每次成功读回设备参数后自动更新。
- 你的原文件可以直接拿来用（`dist\FE5680A.CFG` 就是你原来那份）。
- 如果配置里的串口当前不存在（例如插在 COM3 而配置写 COM4），启动时日志会明确提示。

## 六、自检与截图（开发用）

`dist\FE5680A_Selftest.exe` 与主程序同一个源码，只是以控制台方式编译，用于跑协议自检：

```powershell
.\FE5680A_Selftest.exe --selftest
```

当前 **59 项全部通过**，覆盖：控制字↔频率往返（含作者笔记中实机记录 `R=50255056.078356Hz
F=2ABB5041FFFFFFFF` ⇒ 8.388608 MHz 的核对）、参考频率格式化、设备响应解析（含容错变体）、
中缀/RPN 表达式求值、序列号字段、以及模拟器端到端收发。报告见 `docs\selftest.txt`。

另外两个开发用开关（主程序同样支持）：

```powershell
.\FE5680A_GUI.exe --render docs\ui.png trace.log sim   # 离屏渲染界面 + 连模拟器 + 版面自检
```

界面自检会检查控件是否越界、同级控件是否重叠，当前 `issues=0`（见 `docs\ui.png`）。

## 七、从源码编译

需要 Windows 自带的 .NET Framework 4.x（Win10 默认已装 4.8），**不需要 Visual Studio、不需要 SDK**：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

脚本用 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 编译出：

- `dist\FE5680A_GUI.exe` —— 主程序（约 43 KB，单文件、无外部依赖）
- `dist\FE5680A_Selftest.exe` —— 协议自检

> 若直接运行 `build.ps1` 提示"禁止运行脚本"，请用上面的 `-ExecutionPolicy Bypass` 方式。

源码结构：

```
FE5680A_GUI\
├─ build.ps1                    构建脚本
├─ src\FE5680A_GUI.cs           全部源码（协议层 / 表达式 / 设备 / 界面 / 自检）
├─ tools\CaptureWindow.cs       开发辅助：抓窗口位图
├─ docs\ui.png                  界面截图
├─ docs\selftest.txt            自检报告
└─ dist\                        编译产物 + FE5680A.CFG
```

源码内部分成清晰的几层：`Proto`（协议与换算）、`Expr`（中缀 + RPN 求值）、
`IFreqDevice`/`SerialDevice`/`SimulatorDevice`（设备抽象，模拟器就是同一接口的假实现）、
`Worker`（串口收发在工作线程，界面不卡）、`MainForm`（界面）、`SelfTest`（自检）。

## 八、已知限制与注意事项

- **串口独占**：Windows 下串口同一时刻只能被一个程序打开。如果连接失败，先关掉其他串口工具
  （原 DOSBox、串口助手等）。
- **EEPROM 写入不可逆**：点 [写入 EEPROM] 会覆盖设备原设置，程序会先确认。要恢复原值，请先
  [读取参数] 记下参考频率和控制字。
- **序列号字段是 8 位十六进制**：输入不足 8 位会自动左补 0（例如 `5227` → `00005227`），
  这与原程序直接拼接字符串的行为略有不同（原版会把不足 8 位直接拼上去，容易错位）。
- 参考频率范围限制 50255000 ~ 50255100 Hz 沿用原程序，如你的设备参考频率在范围外，可自行改
  `Proto.RefMin` / `Proto.RefMax` 后重新编译。
- 界面使用固定字号布局，在 125%/150% 缩放的屏幕上由 Windows 缩放显示，功能不受影响。
- 程序不做单位自动换算（Hz/MHz 由界面同时显示），不联网、不写注册表，只在自身目录读写
  `FE5680A.CFG`。
